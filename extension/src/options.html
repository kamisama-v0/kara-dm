About

Kara DM sends downloads to Kara Download Manager over ws://127.0.0.1:10007, the same protocol as the Neat Download Manager app, so it also works with NDM on Windows/macOS. No data is sent to the internet.

Video: play it for a moment so the stream is detected, then use the button on the player or the popup. "This page's video" downloads through yt-dlp (YouTube, Vimeo, X, …).

Turn off the official NDM extension if it is still installed, so downloads are not caught twice.
